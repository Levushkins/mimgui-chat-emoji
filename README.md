# Смайлы из `_chat.asi` в mimgui

Разбор плагина чата Arizona Games (`_chat.asi`), извлечение всех **1584 смайлов и иконок**
в том же порядке, что и в панели чата, и готовый модуль для их отрисовки
и использования в mimgui.

---

## 1. Что внутри `_chat.asi`

`_chat.asi` - это PE32 DLL (ImGui + FreeType + lunasvg, PDB-путь
`C:\source\imgui-chat\...\_chat.pdb`). Смайлы там лежат в трёх местах:

### Списки панели

Панель строится из **семи массивов `uint32`** в `.rdata` - по одному на вкладку.
Каждый адресуется прямо из кода, и порядок обращений в `.text` задаёт порядок
вкладок:

| адрес | штук | содержимое |
|-------|------|------------|
| `0x100CAEB8` | 269 | смайлы и животные |
| `0x100CACB0` | 130 | люди и жесты |
| `0x100CA4E0` | 346 | праздники и предметы |
| `0x100CAA48` | 153 | еда и растения |
| `0x100CA1A8` | 205 | транспорт и места |
| `0x100CB2F0` | 210 | символы |
| `0x100CB640` | 41 | буквы-плашки, цифры и логотипы серверов |

Последняя вкладка добирается прямо в коде: в `.rdata` лежат только первые 16
букв (их копирует один развёрнутый SSE-блок), буквы `Q`–`Z` плагин генерирует
циклом от `U+1F1E6`, а цифры `0`–`9` (`U+1FC10…U+1FC19`) и пять логотипов
серверов записаны отдельными инструкциями. Извлекатель дочитывает этот хвост,
сканируя immediate в `.text` после последнего обращения к массиву.

Итого **1354** смайла в порядке, совпадающем со стандартным Unicode/CLDR.
Группировка у Arizona своя: животные лежат вместе со смайлами, растения - с
едой, часы - с сердцами.

### Таблица имён

Отдельно, в `.data` по адресу `0x100E1FF0`, лежит массив из 825 структур:

```c
struct { const char* name; uint32_t codepoint; };
```

Например `{"smiley", 0x1F603}`, `{"arz", 0x1FC08}`, `{":)", 0x1F642}`.

Это **словарь текстовых шорткатов, а не список панели**: у 563 смайлов панели
имени нет вовсе, а 57 имён (серверные иконки Arizona - `arz`, `redcode`, `buy`,
`ВИП ЧАТ` и подобные) в панель не попали, хотя в чат их вставить можно.

### Скрытые иконки

Сверх этого в `icons.ttf` лежит ещё **188 глифов**, которые не объявлены нигде:
ни в панели, ни в таблице шорткатов. В чате они рисуются - это ленты и плашки
ников, короны VIP, крылья-уровни, значки лавок и недвижимости, телефоны, деньги
и целый набор оружия. Извлекатель вычитывает их прямо из cmap шрифта и кладёт в
конец отдельными группами:

| группа | штук |
|--------|------|
| Скрытые: интерфейс | 12 |
| Скрытые: ленты и плашки | 53 |
| Скрытые: VIP и уровни | 27 |
| Скрытые: значки сервера | 14 |
| Скрытые: цифры и метки | 17 |
| Скрытые: оружие | 65 |
| Скрытые: недвижимость и чат | 32 |
| Скрытые: интерфейс (big_icons) | 10 |

Плюс `big_icons.ttf` - второй шрифт плагина, крупные иконки интерфейса
(пузырь чата, череп, плашка «ТЯЖЕЛО РАНЕН»). Десять его кодовых точек не
пересекаются с `icons.ttf`, они вынесены отдельной группой. В чат эти,
скорее всего, не вставляются - текст чата рисуется другим шрифтом.

Итого в атласе **1584** записи: 1354 из панели чата плюс 230 скрытых.
Это **все** глифы обоих шрифтов иконок, ничего не осталось.

### Шрифты

Четыре шрифта лежат в ресурсах `RCDATA` в **сжатом виде**. Формат сжатия -
`stb_compress` (сигнатура `0x57bC0000`), тот самый, что выдаёт утилита ImGui
`binary_to_compressed_c`:

| ресурс | шрифт | что содержит |
|--------|-------|--------------|
| 101 | Arial Bold | текст чата |
| 102 | Heading Now Medium | заголовки |
| 103 | **icons** (COLR + CPAL + SVG) | серверные иконки: `U+F003…U+F341`, `U+1FC00…U+1FC38`, буквы-плашки `U+1F1E6…U+1F1FF` |
| 104 | **big_icons** (COLR + CPAL) | крупные иконки интерфейса |

### Стандартные смайлы

Их в плагине **нет**. `U+1F600` и соседей чат берёт из системного
**Segoe UI Emoji**: читает реестр
`SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts` → `Segoe UI Emoji (TrueType)`
→ `%WINDIR%\Fonts\seguiemj.ttf`, а если рядом лежит
`fontcustom\seguiemj_1.45.ttf` - берёт его.

### Как смайл попадает в текст

Токеном `:u<hex>:` - формат `":u%x:"` в бинарнике. То есть 😃 в строке чата
выглядит как `:u1f603:`. Рядом живут `:item%d:` и `:slot%d_%d:` для предметов.

## 2. Почему смайлы нельзя просто подключить шрифтом

Напрашивается `AddFontFromFileTTF('seguiemj.ttf', ...)`, но так не выйдет -
по двум независимым причинам:

1. **mimgui собран со `stb_truetype`.** Он растеризует только контуры `glyf` и
   ничего не знает про `COLR`/`CPAL` и `SVG `. У цветных шрифтов базовый контур
   глифа обычно пустой - весь рисунок лежит в цветных слоях. На выходе получатся
   пустые прямоугольники.
2. **`ImWchar` в mimgui 16-битный.** Смайлы живут в `U+1F300…U+1FAFF`, то есть
   выше `U+FFFF`. Такие кодовые точки в 16-битный тип физически не влезают, и
   `GlyphRanges` их не примет.

Поэтому рабочий путь ровно один: **заранее растеризовать смайлы в текстуру**
и рисовать их через `imgui.Image` / draw list. Этим и занимаются скрипты ниже.

## 4. Установка

Скопируйте содержимое `moonloader/` в папку `moonloader` в каталоге игры:

```
moonloader/chat_emoji_minimal.lua
moonloader/lib/chat_emoji.lua
moonloader/resource/chat_emoji/chat_emoji.png
moonloader/resource/chat_emoji/chat_emoji_atlas.lua
```

Зайдите в игру и введите `/sm`.

Кладите **что-то одно** - `chat_emoji_minimal.lua` либо `chat_emoji_demo.lua`:
MoonLoader запускает все `.lua` из своей папки, и два скрипта просто дважды
загрузят один и тот же атлас.

> **Про внешний вид - как сделать 1 в 1 с чатом.**
> Серверные иконки (логотипы, ВИП ЧАТ, короны, оружие, лавки) берутся из
> `icons.ttf` самого плагина, поэтому они **уже один в один**.
>
> А вот обычные смайлы в готовом атласе нарисованы шрифтом **Noto Color Emoji**:
> чат использует Segoe UI Emoji, но это системный шрифт Windows и класть его в
> репозиторий нельзя. Коды, порядок и состав те же - отличается только рисовка.
>
> Чтобы получить ровно тот вид, что в чате, запустите **`rebuild.bat`** двойным
> кликом. Он сам найдёт Python, поставит Pillow, отыщет ваш `seguiemj.ttf`
> (сперва `moonloader\fontcustom\seguiemj_1.45.ttf`, который использует сам чат,
> потом `%WINDIR%\Fonts\seguiemj.ttf`) и пересоберёт атлас. После этого
> скопируйте `chat_emoji.png` и `chat_emoji_atlas.lua` в игру с заменой.

## 5. Использование

```lua
local imgui = require 'mimgui'
local emoji = require 'chat_emoji'

imgui.OnInitialize(function()
    local ok, err = emoji.load()      -- грузит атлас и создаёт текстуру
    if not ok then print(err) end
end)
```

### Нарисовать смайл

```lua
emoji.image('smiley', 24)     -- по имени
emoji.image(0x1F603, 24)      -- по кодовой точке
emoji.image(':u1f603:', 24)   -- по токену
```

### Кнопка со смайлом

```lua
if emoji.button('arz', 32) then
    print('нажали на логотип Arizona')
end
```

### Текст со смайлами внутри

```lua
emoji.text('привет :u1f603: как дела :u1f44b:')
```

`emoji.text` разбирает строку на куски, текст рисует через `TextUnformatted`,
а смайлы - картинками, центруя их по высоте строки.

### Размер

Размер задаётся при каждой отрисовке и ничем не зафиксирован - это текстура,
а не шрифт:

```lua
emoji.image('arz', 16)
emoji.image('arz', 48)
emoji.image('arz', customSize[0])   -- хоть из слайдера, хоть каждый кадр
```

Аргумент - **высота в пикселях**, ширина считается сама (`size * cells`).
Демка `/emj` показывает одну и ту же иконку сразу в семи размерах плюс
слайдер 8–128 px.

Ячейка атласа 40 px, поэтому до 40 px картинка идеальна, до ~64 px разницы
почти не видно, а дальше начинает мылить - особенно у широких баннеров с
текстом. Нужен крупный размер - пересоберите с `--cell 64`, но атлас тогда
станет 2048×4096 и займёт 32 МБ видеопамяти вместо 16.

### Несколько скриптов сразу

MoonLoader запускает каждый скрипт в отдельной Lua-машине, поэтому раньше три
скрипта с этой библиотекой создавали три копии одной текстуры, по 16 МБ
видеопамяти каждая.

Теперь текстура одна на процесс. Машины разные, но процесс общий, так что
указатель передаётся через переменную окружения процесса, а время жизни
считает сам COM: тот, кто нашёл готовую текстуру, делает `AddRef`, при
выгрузке каждый делает `Release`. Слот освобождается, когда `Release` вернул
ноль, то есть когда отпустил последний скрипт.

Ключ включает путь к атласу и число записей, поэтому два разных атласа не
перепутаются. Проверить, досталась ли готовая текстура, можно через
`emoji.sharedTexture`.

### Пропорции между иконками

Все глифы масштабируются **одним общим множителем**, а не подгоняются каждый
под свою ячейку. Иначе мелкий значок раздувался бы до размера крупного
баннера, и при одном и том же `size` одна иконка выглядела бы больше другой.
Чат рисует их одним кеглем - здесь так же.

Множитель считается по самому высокому глифу шрифта (`U+F2FF`, 1.35 em),
поэтому типичная иконка занимает около 80 % высоты ячейки, а мелкие
служебные метки остаются мелкими - как и в игре.

### Широкие иконки

Серверные баннеры (`ВИП ЧАТ`, `РЕКЛАМА`, ленты под ники, `BUY`/`SELL`) бывают
до **8.6 раза шире своей высоты**. Если запихнуть такой глиф в квадратную
ячейку, от него остаётся нечитаемая полоска в несколько пикселей - именно так
и выглядели «обрезанные» иконки.

Поэтому в атласе широкий глиф занимает **несколько ячеек подряд** (до восьми),
а в записи хранится их число - `e.cells`. Все функции рисуют с этим
соотношением: высота задаётся аргументом `size`, ширина получается
`size * cells`. Панель выбора тоже считает перенос строки по фактической
ширине кнопок, а не по их количеству.

```lua
local e = emoji.get('buy')
print(e.cells)                  -- 3
print(emoji.width('buy', 24))   -- 72 - столько займёт по горизонтали
```

### Панель выбора

```lua
local picked = emoji.picker('grid', 24, 300)   -- id, размер, высота
if picked then
    sampSendChat(emoji.encode(picked))         -- отправит ':u1f603:'
end
```

Панель - это поиск по имени плюс сетка, разбитая на вкладки в том же порядке,
что и в чате: «Смайлы и животные», «Люди и жесты», «Праздники и предметы»,
«Еда и растения», «Транспорт и места», «Символы», «Буквы и логотипы» и
«Сервер (вне панели чата)». Поиск понимает и синонимы - `:)`, `<3` и прочие
текстовые шорткаты.

### Про кодировку и `u8`

**Кодировка файлов здесь ни на что не влияет** - это сделано намеренно.
В `.lua` нет ни одного русского литерала: подписи модуля латиницей, а названия
категорий приходят из описания атласа, где записаны escape-последовательностями
(`'\208\161...'`). Такой файл можно пересохранить хоть в cp1251, хоть в UTF-8 -
на экране всё останется как было.

Свои надписи задавайте через `emoji.strings` (файл со своим текстом уже
сохраняйте в UTF-8, ImGui ждёт именно его):

```lua
emoji.strings.search = 'Поиск...'
```

Привычная обёртка `u8'текст'` нужна для скриптов, сохранённых в cp1251.

Обратное направление требуется при разговоре с SA-MP - он работает в cp1251:

```lua
local encoding = require 'encoding'
encoding.default = 'CP1251'
local u8 = encoding.UTF8

sampSendChat(u8:decode(текстИзImGui))   -- UTF-8 -> cp1251
```

Сам токен `:uXXXX:` - цифры и латиница, его перекодировать не нужно.

Если сохраните свой скрипт в cp1251, литералы наоборот оборачивайте в `u8()`.

### Отправить смайл в чат

```lua
sampSendChat('всем привет ' .. emoji.encode('smiley'))
```

Плагин чата сам подменит `:u1f603:` на картинку - и у вас, и у остальных
игроков с этим плагином.

### Полный список API

| функция | описание |
|---------|----------|
| `emoji.load([dir])` | загрузить атлас и текстуру; `true` либо `false, ошибка` |
| `emoji.unload()` | освободить текстуру (в `onScriptTerminate`) |
| `emoji.get(key)` | запись по имени, коду, токену или самой записи |
| `emoji.encode(key)` | токен `:uXXXX:` для чата |
| `emoji.parse(str)` | разбор строки на куски текста и смайлы |
| `emoji.image(key, size)` | нарисовать картинкой (ширина = `size * cells`) |
| `emoji.width(key, size)` | какую ширину займёт смайл при высоте `size` |
| `emoji.button(key, size, [id])` | кнопка, возвращает `true` при нажатии |
| `emoji.text(str, [size])` | текст с подстановкой смайлов |
| `emoji.picker(id, [size], [height])` | панель выбора, возвращает запись либо `nil` |
| `emoji.list` | массив всех 1584 записей: сперва панель чата, потом скрытые |
| `emoji.byName`, `emoji.byCp` | таблицы поиска |
| `emoji.categories` | `{ { name = 'Смайлы', items = {...} }, ... }` |

Запись смайла:

```lua
{ name = 'smiley', cp = 0x1F603, cat = 'Смайлы',
  slot = 20, index = 21, token = ':u1f603:',
  uv0 = ImVec2(...), uv1 = ImVec2(...) }
```

## 6. Пересборка

### Извлечь всё заново из `_chat.asi`

```bash
python3 tools/extract_chat_emoji.py /путь/к/_chat.asi -o data
```

Зависимостей нет - только стандартная библиотека Python. Скрипт сам разбирает
PE, распаковывает `stb_compress` и находит таблицу смайлов.

### Собрать всё с нуля одной кнопкой

`rebuild.bat` делает полный цикл: находит Python, ставит Pillow, ищет ваш
`_chat.asi`, распаковывает из него шрифты и списки смайлов, ищет ваш
`seguiemj.ttf` и собирает атлас. Пути можно задать и вручную:

```
rebuild.bat --asi "C:\...\bin\arizona\_chat.asi"
rebuild.bat --emoji "C:\Windows\Fonts\seguiemj.ttf"
```

Сам `.bat` - тонкая обёртка на латинице: он только находит Python и ставит
Pillow, а всё остальное делает `tools/rebuild.py`. Так сделано намеренно -
cmd.exe читает батник в кодировке консоли, и любой не-ASCII символ внутри
ломает разбор команд.

Это же и способ распространять библиотеку, ничего чужого не выкладывая:
достаточно отдать код и `tools/`, а атлас каждый соберёт себе сам - заодно
получит рисовку ровно как у себя в чате.

### Собрать атлас на своём Segoe UI Emoji

```bash
pip install pillow

python3 tools/build_emoji_atlas.py data/emoji.json \
    --icons data/icons.ttf \
    --emoji "C:/Windows/Fonts/seguiemj.ttf" \
    -o moonloader/resource/chat_emoji \
    --cell 48
```

Если `--emoji` не указать, скрипт сам поищет `%WINDIR%\Fonts\seguiemj.ttf`.

Полезные ключи:

* `--cell 64` - крупнее ячейка, чётче при большом размере, но тяжелее текстура
* `--width 2048` - ширина атласа (высота подбирается сама, до степени двойки)
* `--pad 2` - отступ внутри ячейки

Серверные иконки (`U+F2xx`, `U+1FCxx`, буквы-плашки) всегда берутся из
`icons.ttf`, остальное - из эмодзи-шрифта.

### Проверить модуль

```bash
luajit tools/test_chat_emoji.lua
```

Тест подменяет mimgui и API MoonLoader, проверяет описание атласа, UV-координаты,
поиск и разбор строк - игра для этого не нужна.

## 7. Как это работает внутри

**Текстура.** `chat_emoji.lua` читает PNG в память и создаёт текстуру D3D9 через
`D3DXCreateTextureFromFileInMemoryEx` из `d3dx9_XX.dll` (перебираются версии
43…24), передавая устройство из `getD3DDevicePtr()`. Пул - `D3DPOOL_MANAGED`,
поэтому текстура переживает device reset и пересоздавать её при смене разрешения
не нужно.

**UV.** В описании у каждого смайла хранится только номер ячейки `slot`,
а координаты считаются на загрузке:

```lua
col  = slot % cols
line = math.floor(slot / cols)
uv0  = ImVec2(col * cell / width, line * cell / height)
```

**Кнопки.** `emoji.button` сделана на `InvisibleButton` + draw list, а не на
`ImageButton`. Причина: у всех кнопок одна и та же текстура, а `ImageButton`
берёт ID именно из неё - вся сетка слиплась бы в один элемент. Побочная польза:
код не зависит от того, какая сигнатура `ImageButton` в конкретной сборке mimgui.

**Растеризация.** У цветных шрифтов базовый контур глифа пустой, поэтому Pillow
на строке из одного такого символа считает высоту маски нулевой и не рисует
ничего. `build_emoji_atlas.py` обходит это, дорисовывая справа символ, которого в
шрифте заведомо нет (`U+E123`): он рисуется как `.notdef` с непустым контуром,
маска получает нормальную высоту, а сам `.notdef` отрезается по ширине аванса.
