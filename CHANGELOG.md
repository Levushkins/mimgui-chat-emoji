# Changelog

## 3.2 - октябрь 2026

### Новое в данных

* Набор пересобран из `_chat.asi` от 08.09.2026: **1598** записей вместо 1584.
  Добавлены 14 иконок `U+1FC39…U+1FC46` - Telegram, VK и логотипы компаний
  с биржи (`telegram`, `vk`, `alphabet`, `amazon`, `apple`, `bmw`, `mercedes`,
  `microsoft`, `nvidia`, `sp500`, `spacex`, `tesla`, `toyota`, `volksw`).
  Они лежат в новой категории «Скрытые: биржа и соцсети» (`hidden_brands`).
* **Ломающее изменение в данных плагина:** имя `apple` теперь у логотипа Apple,
  у 🍎 имени в таблице плагина больше нет. Яблоко находится как `red_apple`:
  у всех стандартных смайлов появились синонимы из базы Unicode.
* Атлас 2048×1360 вместо 2048×2048 (высота больше не округляется до степени
  двойки): 10.6 МБ видеопамяти вместо 16.
* Малый атлас `chat_emoji_small.png` (1024×680, ячейка 20 px) для смайлов до 20 px.
* `chat_emoji_search.lua` - русские ключевые слова из Unicode CLDR и подписи иконок
  Arizona. Грузится только при первом поиске кириллицей.
* Описание атласа версии 3: `hash`, `small`, `source`, `categories`. Записи
  прежние, библиотека 3.1 читает его без изменений.

### Новое в библиотеке

* `emoji.fontGlyphs()`, `glyph()`, `toGlyphs()`, `fromGlyphs()` - смайлы в шрифте
  ImGui, работают в любых виджетах и в `InputText` при наборе.
  `emoji.inputText(..., { glyphs = true })` вставляет глифы.
* Поиск по-русски, по названиям категорий и с неправильной раскладкой; результаты
  `emoji.find()` отсортированы по качеству совпадения.
* `emoji.toUnicode()`, `emoji.fromUnicode()` - мост с Telegram, VK, Discord.
* `emoji.weapon(id)`, `emoji.crown(n)`, `emoji.wings(n)`.
* `emoji.category()` принимает короткое имя категории (`'hidden_weapons'`),
  у записей и категорий есть поле `catId` / `id`.
* `emoji.canRender()` и `emoji.serverSupports()`; `emoji.fit(text, 'server')`.
  `emoji.detect()` остался синонимом `canRender()`.
* `emoji.checkSource()`, `emoji.stale`, `emoji.QUIET`: библиотека замечает, что
  атлас собран для другой версии `_chat.asi`, и один раз пишет об этом в лог.
* `emoji.FORMAT = 'dxt5'`, `emoji.SMALL`, `emoji.SMALL_BELOW`.
* `emoji.atLeast(version)`, `emoji.setPickerQuery(id, text)`,
  `emoji.clearLayoutCache()`.
* Аннотации LuaLS для публичных функций, класс записи `ChatEmoji`.

### Исправлено

* **`drawText`, `drawImage` и `draw3D` в 3.1 ничего не рисовали, а `tooltipText`
  показывал токены текстом.** Функции mimgui - это C-функции, `type()` у них
  `'cdata'`, а библиотека проверяла `== 'function'` и считала их отсутствующими.
  Найдено проверкой в игре.
* Панель выбора при поиске показывает один список «Найдено», лучшие совпадения
  первыми (`opts.grouped = true` вернёт разбивку по категориям).
* `sendChat` отправлял все части длинного сообщения в одном кадре, и антифлуд
  сервера съедал всё, кроме первой. Теперь между частями пауза
  `emoji.CHAT_DELAY` (1100 мс); второй аргумент может быть таблицей
  `{ limit, delay }`.
* `sendChat` на чужом сервере оставлял токены: лаунчер Arizona грузит плагин чата
  везде, и проверка «плагин загружен» пропускала `:u1f603:` к остальным игрокам.
* `reload()` после пересборки атласа с тем же числом смайлов получал старую
  текстуру из соседнего скрипта: в ключ общей текстуры вошли хеш атласа и формат.
* Последний держатель старой общей текстуры стирал из слота новую. Слот теперь
  стирается, только если в нём адрес именно отпускаемой текстуры. Слоты
  переименованы, чтобы с ними не конфликтовали 3.1 и старше.
* Если D3DX округлял размер текстуры (старые видеокарты без NONPOW2), все смайлы
  съезжали: UV теперь считаются от настоящего размера (`GetLevelDesc`).
* `text()` и виджеты меряли каждое слово каждый кадр: добавлен кеш раскладки.

### Инструменты

* `extract_chat_emoji.py` пишет `source.json` (размер, время сборки и SHA-1
  `_chat.asi`) и ASCII-имена категорий.
* `build_emoji_atlas.py`: высота без округления (`--pow2` вернёт старое), малый
  атлас (`--no-small` отключит), хеши, синонимы из Unicode, файл русского поиска.
* `cldr_ru.py` - русские ключевые слова из Unicode CLDR.
* `rebuild.py` ищет `fontcustom\seguiemj_1.45.ttf` рядом с указанным `_chat.asi`.
* `test_chat_emoji.lua` покрывает всё новое; `ingame_check.lua` - проверка в игре.
* Пример `chat_emoji_showcase.lua` с автотуром для записи видео.
* `data/arial.ttf` и `data/heading_now.ttf` убраны из репозитория, как и было
  заявлено в README: это коммерческие шрифты.

  `{RRGGBB}`, рисует одним проходом по draw list; `calcTextSize()`.

  избранное, недавние и всплывающий вариант; `pickerPopup()`, `pickerButton()`,
  `inputText()`.
* `emoji.split()`, `emoji.sendChat()`, `emoji.stylize()`, `letter()`, `digit()`,
  `number()`, `decode()`, `find()`, `category()`, `random()`, `reload()`,
  `info()`, `selfTest()`.
* Текстура освобождается сама, если скрипт забыл вызвать `unload()`.
